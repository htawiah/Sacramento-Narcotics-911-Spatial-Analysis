# Drug Abuse Prevention: Spatial Analysis of Narcotics-Related 911 Calls

A GIS and Python project analyzing narcotics-related 911 calls across Sacramento neighborhoods to identify spatial patterns and examine incident frequency.

## Project Objective

Analyze narcotics-related 911 calls across Sacramento neighborhoods to identify where incidents occurred and examine their frequency by day of the week.

## Tools & Technologies

- Python
- ArcPy
- ArcGIS Pro
- ArcGIS Online
- Spatial Analysis
- Geospatial Data Processing

## Methodology

The workflow used Python and ArcPy to automate neighborhood-level analysis of 911 call data. Attribute and spatial selections were used to identify narcotics-related incidents, determine their neighborhood locations, count incidents, and summarize their frequency by day of the week.

## Key Results

- **64 narcotics-related 911 calls** were identified in the analyzed dataset.
- Incidents were not evenly distributed across the study area.
- A greater concentration of incidents was observed within northern neighborhoods.
- The workflow demonstrates the use of Python and GIS for automated spatial analysis of emergency-call data.
